# 短剧 HTTP 边界

`dramaRoutes.ts` 是 app 挂载门面，负责项目、剧本、角色、生产命令的 HTTP 映射；`imageFileRoutes.ts` 独立承担镜头首帧、角色图和历史版本的文件响应。业务逻辑、路径解析、文件存在性判断由既有 drama services 所有。外部模块只依赖门面。

文件解析与读取之间仍可能出现删除/替换，因此发送必须处理异步错误。使用 Express sendFile 收口文件描述符和客户端断开：尚未响应时错误传给中间件，已响应时只能关闭连接，已断开的请求不再写 JSON。保留现存 URL，由调用方审计决定是否淘汰旧入口，不能仅凭兼容注释删除。
